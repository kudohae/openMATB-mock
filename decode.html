결과 코드 → 표(CSV) 변환기

구글 시트의 결과 코드 열 전체를 복사해 아래에 붙여 넣으세요(한 줄에 코드 하나). 변환 결과는 CSV로 내려받아 엑셀, JASP, R에서 바로 열 수 있습니다. 행 순서는 붙여 넣은 순서와 같으므로 설문 응답과 그대로 나란히 붙이면 됩니다.

이 페이지는 데이터를 어디에도 보내지 않습니다. 모든 처리는 이 브라우저 안에서만 일어납니다.

열 설명

  • valid: 1이면 코드가 손상·수정되지 않음. 0이면 제외 권장 · session: 기록 파일 이름(날짜·시각, 중복 확인용)
  • A_trk_in / A_trk_rms: 과제 1(추적 + 교신, 본 측정 150초)에서 커서가 원 안에 있던 비율(%) / 중심과의 거리 RMS(픽셀, 낮을수록 정확)
  • A_cm_*: 과제 1 교신(내 호출 4건). 열 이름은 아래 B_cm_*와 같은 뜻
  • B_sm_man_n / B_sm_man_hit / B_sm_man_rt: 주 준거. 과제 2(5분)에서 자동 장치가 놓치는 이상의 수(6) / 그중 참가자가 10초 안에 처리한 수 / 그 평균 반응시간(ms)
  • B_trk_in / B_trk_rms: 과제 2 중 추적의 같은 지표
  • B_sm_hit / B_sm_auto / B_sm_miss / B_sm_fa / B_sm_rt: 시스템 감시 전체. 참가자가 처리한 이상 / 자동 장치가 처리한 이상 / 10초 안에 처리되지 않은 이상 / 이상이 없는데 누른 횟수 / 참가자 처리의 평균 반응시간(ms)
  • B_cm_hit / miss / fa / bad_radio / bad_freq / bad_radio_freq / B_cm_rt: 교신(내 호출 8건). 정답 / 무응답 / 남의 호출에 응답 / 무전기 틀림 / 주파수 틀림 / 둘 다 틀림 / 정답의 평균 반응시간(ms, 음성이 끝난 뒤부터)
  • B_rm_a / B_rm_b / B_rm: 연료 관리. 탱크 A, B가 목표 범위 안에 있던 시간 비율(%)과 그 평균
  • hidden: 과업 중 다른 탭·창으로 나간 횟수(1 이상이면 검토) · pointer_lost: 추적 중 마우스 잠금이 풀린 횟수(Esc 등) · freeze_ms: 브라우저가 멈춘 시간 합계(ms, 수천 ms 이상이면 검토)
  • browser / voice / win_h: 브라우저, 사용된 한국어 음성, 창 높이(픽셀). voice가 비어 있으면 음성이 안 나왔을 수 있으므로 제외 검토
