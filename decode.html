결과 코드 → 표(CSV) 변환기

구글 시트의 결과 코드 열 전체를 복사해 아래에 붙여 넣으세요(한 줄에 코드 하나). 변환 결과는 CSV로 내려받아 엑셀이나 JASP에서 바로 열 수 있습니다.

이 페이지도 데이터를 어디에도 보내지 않습니다. 모든 처리는 이 브라우저 안에서만 일어납니다.

열 설명

  • valid: 1이면 코드가 손상·수정되지 않음, 0이면 제외 권장
  • A_trk: 과제 A 추적 오차(낮을수록 정확). 화면 대비 % 단위 RMSE
  • B_trk: 과제 B 중 추적 오차
  • B_smN / B_smHit / B_smMiss / B_smRT / B_smFA: 자동화가 놓친 시스템 이상의 개수 / 처리 / 놓침 / 평균 반응시간(초) / 이상 없는데 누른 횟수
  • B_cmN / B_cmHit / B_cmMiss / B_cmWrong / B_cmRT / B_cmFA: 내 호출부호 교신 수 / 정답 / 놓침 / 채널 틀림 / 평균 반응시간 / 남의 호출에 반응
  • B_rmBoth: 두 탱크가 모두 범위 안에 있던 시간 비율(%)
  • B_attn: 주의 확인 통과(1) / 실패(0). 0이면 제외 권장
  • away: 과제 중 다른 탭으로 이동한 횟수. 1 이상이면 검토
  • fast: 1이면 점검용 단축 모드로 응답한 것이므로 제외
