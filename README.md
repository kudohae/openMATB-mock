# OpenMATB 한국어 연구판

2026 공군사관학교 미래 항공우주 학술대회 발표 연구에 쓰는 웹 과제입니다. Cegarra & Valéry의 **OpenMATB 1.5.0** 웹판(https://github.com/juliencegarra/OpenMATB, 커밋 a9405a9)을 한국어 참가자용으로 고친 것입니다.

- 참가자 주소: 저장소의 GitHub Pages 첫 화면. 설문 링크를 붙이려면 주소 뒤에 `?form=<구글 폼 주소>`를 붙입니다.
- 원래 OpenMATB 메뉴: `?admin=1`
- 결과 코드 변환기: `decode.html`
- 이전에 쓰던 단순화 모의 과제: `mock/` (연구에는 쓰지 않음)

## 원본에서 바꾼 점

- 교신 음성: 녹음된 영어 음성 대신 브라우저의 한국어 음성 합성(TTS). 글자와 숫자를 하나씩 끊어 읽고(숫자는 무전식: 하나, 둘, 삼, 넷, 오, 여섯, 칠, 팔, 아홉, 공), 소수점은 "쩜"으로 읽습니다. 응답 시간은 음성이 끝난 시점부터 잽니다.
- 키 배정(숫자 키패드 없음): 시스템 감시 1~6, 펌프 Q W E R A S D F, 교신은 원본 기본값인 ↑↓(무전기) ←→(주파수) Enter(확인).
- 추적: 시작 버튼을 누르는 순간 마우스 포인터가 고정되어 숨겨지고(포인터 잠금), 마우스를 움직인 만큼 초록 커서가 움직입니다(`track;mousemove`). 브라우저가 첫 잠금을 거절하거나 Esc로 풀리면, 다음에 누르는 키(Esc 제외)나 클릭으로 다시 고정합니다. 잠금이 풀린 횟수를 기록합니다.
- 교신: Enter를 누르면 맞든 틀리든 그 무전기 칸 배경이 0.5초 동안 옅은 초록으로 바뀝니다(`communications;confirmflash`).
- 화면 한국어화(ko_KR 번역, Noto Sans KR 글꼴), 한글 입력기 상태에서도 키가 먹도록 키 처리 보완.
- `guide` 플러그인: 과업 화면을 멈춘 채(가리지 않고) 그 위에 설명 상자와 주황 테두리(과업 칸 전체 또는 일부)를 띄우는 튜토리얼.
- `gate` 플러그인: 교신 튜토리얼에서 첫 정답 응답이 나오면 바로 다음 단계로 넘어갑니다.
- 연구용 시나리오(`includes/scenarios/korean/study.txt`, `make_study.py`로 생성):
  - 과제 1: 공군 조종적성검사(K-PAT) 멀티태스킹 소검사처럼 자동화 없이 추적과 교신을 동시에. 튜토리얼 후 본 측정 150초.
  - 과제 2: 네 과업 동시. 튜토리얼(시스템 감시, 연료 관리), 1분 연습, 본 측정 5분. 시스템 감시 이상 12건의 계기와 자동화 처리 여부(6건 처리, 6건 놓침)는 OpenMATB에 들어 있는 Parasuraman, Molloy & Singh(1993) 저신뢰 블록 앞부분 12건을 따르고, 간격을 5분에 맞게 줄였습니다. 교신 12건과 펌프 고장 3건을 더했습니다.
- 종료 화면에서 요약 점수를 결과 코드(`OM1-…`)로 보여 주고, 원자료는 참가자 브라우저 밖으로 보내지 않습니다. 주 준거는 자동화가 놓친 이상을 참가자가 처리한 수(`B_sm_man_hit`)입니다.

바뀐 소스 전체는 `korean-adaptation.patch`(원본 커밋 기준 `git apply`)에 있습니다. 실행 파일 묶음(`app.zip`)에도 수정된 파이썬 소스가 그대로 들어 있습니다.

## 라이선스

- 끝 화면: 설문 링크가 구글 폼을 열면서 결과 코드 칸을 자동으로 채웁니다(config.ini `web_survey_url`의 `{code}`).
- 연구자 점검용 `?fast=1`: 시나리오 시간이 10배 빠르게 흘러 약 2~3분 만에 끝 화면과 결과 코드를 확인할 수 있습니다(점수는 의미 없음, 참가자에게 주지 않음).
- 결과 코드에 반쪽 점수 추가(신뢰도 추정용): 추적 RMS 앞·뒤 절반(`*_trk_rms_h1/_h2`), 교신 홀·짝 지시 정답 수(`*_cm_hit_o/_e`), 자동화가 놓친 이상 홀·짝 처리 수(`B_sm_man_hit_o/_e`).
- 시작 화면: 자동화 신뢰 성향 6문항과 "전에 해 본 적" 1문항을 테스트 전에 묻고 결과 코드에 넣습니다(`pre_t1`~`pre_t6`, `pre_before`). 휴대폰·태블릿은 시작 버튼이 나오지 않습니다.
- 방문 기록: 연구 화면이 열람(휴대폰이면 "열람(휴대폰, 차단됨)"), 시작, 완료 때마다 연구자의 별도 구글 폼에 단계와 기기 종류(pc/mobile, 브라우저)만 익명으로 한 줄씩 보냅니다. `?fast=1`이면 단계 뒤에 "(fast)"가 붙습니다.
- 휴대폰·태블릿 화면: 테스트 대신 "PC에서 열어 달라"는 안내와 링크 공유(휴대폰 공유 창, 카톡 나와의 채팅 등)·복사 버튼만 보여 주고, 파이썬 실행기(약 20MB)를 내려받지 않습니다. 공유·복사도 방문 기록에 남습니다.
