# OpenMATB 한국어 연구판

2026 공군사관학교 미래 항공우주 학술대회 발표 연구에 쓰는 웹 과제입니다. Cegarra & Valéry의 **OpenMATB 1.5.0**(https://github.com/juliencegarra/OpenMATB, 커밋 a9405a9)의 과업과 연구 시나리오를 브라우저용 자바스크립트로 다시 구현한 것입니다(엔진 `js1`).

- 참가자 주소: 저장소의 GitHub Pages 첫 화면. 설문 주소를 바꾸려면 주소 뒤에 `?form=<구글 폼 주소>`를 붙입니다(`{code}` 자리에 결과 코드가 들어감).
- 결과 코드 변환기: `decode.html`
- 이전판(v1, Pyodide로 원본 파이썬 OpenMATB를 그대로 실행): `v1/`. 원본 대비 한국어 수정분은 `v1/korean-adaptation.patch`
- 이전에 쓰던 단순화 모의 과제: `mock/` (연구에는 쓰지 않음)

## 왜 다시 구현했나

v1은 브라우저 안에서 파이썬(Pyodide)과 pyglet(WebGL)을 돌렸습니다. 실제 참가자들에게서 본 과제 중 화면이 멈추거나 검게 되는 일, 스페이스바가 먹지 않는 일이 반복됐습니다. 원인은 약 20MB의 실행기, WebGL 화면 유실, 파이썬 루프 예외, 포인터 잠금·전체 화면 해제가 서로 얽힌 데 있었습니다. 현재판은 같은 시나리오와 과업 규칙을 Canvas 2D와 DOM으로만 그려 이런 경로를 없앴습니다.

## 원본과 같게 둔 것

- 시나리오: `content/study.txt`, 안내문 `content/instructions/`(v1의 `includes/scenarios/korean/`와 같음). 시나리오 형식(`h:mm:ss;플러그인;명령`)을 그대로 읽습니다.
- 과업 규칙과 수치: 추적(20ms 갱신, 목표 반경 0.25, 마우스 이득 0.5), 시스템 감시(200ms, 경고 시간 10초, 자동 처리 지연 4초), 교신(80ms, 응답 제한 20초, SDT 판정), 연료 관리(2초 갱신, 탱크 손실·펌프 유량·허용 범위 250). 각 파일 주석에 원본 위치를 적었습니다.
- 시나리오 시간: 안내 화면이 떠 있는 동안 멈춤, 튜토리얼 안내 상자(`guide`)는 과업을 보이게 둔 채 멈춤, 교신 튜토리얼의 첫 정답에서 다음 단계로(`gate`).
- 결과 코드 형식(`OM1-…`)과 열 이름, 방문 기록, 시작 전 질문, 휴대폰 차단.

## v1과 다른 점

- 화면: 시작 순간의 창 크기로 과업 배치를 정하고, 창 크기가 바뀌면 비율을 유지한 채 늘리거나 줄입니다. 전체 화면은 쓰지 않습니다.
- 시간: 과업은 고정 간격으로 갱신하고, 한 프레임이 0.25초보다 길면 그 초과분을 멈춤(`freeze_ms`)으로 기록하고 따라잡지 않습니다.
- 마우스: 시작할 때 포인터를 고정합니다. 추적 중 고정이 풀리거나 다른 탭·창으로 가면 모든 과업과 시나리오 시간이 멈추고 주황 안내가 뜹니다. 클릭하면 다시 고정되고 이어집니다.
- 키: 물리 키 위치(`event.code`)로 읽어 한글 입력기 상태와 상관없이 동작합니다. 시스템 감시 1~6, 펌프 Q W E R A S D F, 교신 ↑↓ ←→ Enter. Esc는 무시합니다.
- 교신 음성: 브라우저의 한국어 음성 합성을 한 발화로 읽고, Chrome의 15초 끊김을 막으려 13초마다 잠깐 멈췄다 이어 읽습니다. 음성이 끝 신호를 보내지 않으면 감시 타이머가 넘기고 횟수를 `tts_fail`에 남깁니다.
- 오류: 과제 코드에서 오류가 나면 과업을 멈추고 "지금까지의 결과 코드 받기"를 띄웁니다(`aborted` = "멈춤"). 브라우저 확장 등 다른 스크립트의 오류는 무시합니다.
- 원자료: 끝날 때(오류로 끝날 때 포함) 이름 없는 과제 기록(JSON, 약 50KB: 시나리오 이벤트, 키 입력, 시스템 감시·교신 결과, 탱크 수위, 초당 추적 요약)을 연구자의 DataPipe(https://pipe.jspsych.org) 실험으로 보냅니다. 파일 이름은 결과 코드의 `file`과 같고 확장자만 `.json`입니다. 실패해도 결과 코드는 그대로 나옵니다.
- 교신 반쪽 점수(`*_cm_hit_o/_e`)는 내 호출을 순서대로 홀·짝으로 나눠 셉니다.
- 결과 코드에 `eng`(`js1`)와 `tts_fail`이 추가됐습니다.

## 점검

- `?fast=1`: 시나리오 시간이 10배 빠르게 흐릅니다(점수는 의미 없음, 원자료를 보내지만 `meta.fast`가 true).
- `?bot=1`: 자동 참가자가 과제를 끝까지 수행합니다(점검용, 원자료를 보내지 않음).
